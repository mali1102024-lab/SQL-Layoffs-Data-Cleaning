**Layoffs SQL Project**


**Project Overview**

**Project Title:** Layoffs Data Cleaning & Standardization

**Level:** Beginner–Intermediate

**Database:** layoffs_staging2

This project demonstrates SQL skills in data cleaning and preparation using a layoffs dataset. The focus is on handling nulls, correcting typos, and standardizing industry values. It mirrors real-world data analyst tasks where datasets are messy and require transformation before insights can be derived.

**Objectives**

Database Setup: Create staging tables for layoffs data.
Data Cleaning: Remove nulls, blanks, and duplicates.
Standardization: Fix inconsistent industry names (e.g., “Crypto”, “Fintech”).
Data Quality Checks: Validate cleaned data for consistency and accuracy.
Prepared Dataset: Ensure the dataset is ready for downstream analysis.

**Project Structure**

**Database Setup**
Created a staging table to safely clean data without affecting the raw dataset.

**Data Cleaning**
Checked for nulls and blanks.
Deleted invalid records.
Fixed typos in column names and values.
Standardization
Unified industry names.
Trimmed whitespace and corrected casing.

**Findings**

Nulls & Blanks: Several records had missing industry values, which were removed.
Typos: Columns like industy caused errors — corrected to industry.
Standardization: Industry values were normalized (e.g., “Crypto” consistently applied).

**Prepared Dataset:**
Cleaned data is now reliable for further business analysis.

**Reports**
Industry Distribution: Cleaned list of industries.

**Data Quality Report:**
Summary of nulls, blanks, and corrections applied.

**Conclusion**
This project highlights data cleaning and preparation in SQL, a critical skill for analysts. By handling nulls, fixing typos, and standardizing values, the dataset becomes reliable for further business analysis.
